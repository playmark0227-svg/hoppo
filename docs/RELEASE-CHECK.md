## 修正内容

- Firebase SDKの公式App Check通信先 `content-firebaseappcheck.googleapis.com` をCSPに追加。
- クラウド起動時は旧デモデータを書き戻さず、端末設定・チュートリアル完了状態を保持。
- ログインモーダルの左右の余白を均等化。
- メール形式とパスワード長の判定・エラーを分離。新規登録は最低6文字・確認用入力と一致することを必須にし、ログインと新規登録は別タブへ。
- localStorageへの認証保存を強制する設定を廃止。Firebase既定の保存先選択を使用し、認証後の保存失敗時はメモリー内セッションへ復旧して既存アカウントに再ログイン（登録を重複させない）。この場合は長期保存できない旨を表示。
- 確認メール送信の失敗をアカウント作成失敗と区別。再送ボタン・安全なエラーコード・処理中の二重送信抑止を確認。
- Firebase側の最低6文字設定は利用者の明示承認を得て変更。既存利用者のパスワードは変更していません。SDKもバージョン付きURLで読み込み、旧Service Workerによる混在を回避。
- 初回案内の旧デモ説明を修正。Firebase保存、DMの18歳以上・双方同意・相互フォロー条件、実物交換の未提供を明示。
