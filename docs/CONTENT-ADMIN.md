# コンテンツ管理

2026-10-16：実装・エミュレーターでの操作検証・PC/スマホの画面確認済み。本番反映と初期管理者の指定は、会社アカウントのFirebase再認証および管理者メールアドレスの指定待ちです。以下の入口は公開反映後に使用します。

## 入口

https://hoppo-status.vifight.com/#admin

承認された管理者アカウントでログインすると、設定画面に「コンテンツ管理」が表示されます。URLを知っているだけでは管理操作はできません。権限がないアカウントには下書き・発行コード・変更履歴を返しません。

## スタンプとQR

1. 「スタンプ」→「新規追加」で、タイトル・番号・場所・ヒント・取得後の説明を入力します。所在地・緯度経度・画像URL・補足情報も設定できます。
2. 「下書き保存」で内容を保存し、「公開」で利用者の図鑑へ反映します。
3. 「このスタンプのQRを発行」から、参加ポイントと有効期限を指定して発行します。
4. PNG画像の保存・印刷・コードのコピーができます。「イベントQR」から再表示や無効化もできます。

スタンプ付きQRは、別のQRを発行しても同じ利用者には同じスタンプのポイントを二重付与しません。スタンプなしのイベントQRは、コードごとに1回だけ付与します。1コードのポイントは0〜500pt、有効期限は最長1年です。

QRは位置証明ではありません。コード画像の共有先からも利用できるため、会場内に掲示し、不要になったコードは無効化してください。緯度経度は案内地図に利用し、GPS到着判定は行いません。

## クイズ

タイトル・難易度・紹介・設問・選択肢・正解・解説・政府出典を編集できます。出典URLは日本政府機関のHTTPS（`.go.jp`）のみ受け付けます。ドメイン検証だけでは設問の正しさを保証できないため、公開前に資料と照合し、内容確認へチェックします。

設問等の変更時には、そのクイズだけ版を更新します。別のクイズの成績と累計ポイントは維持します。変更前に開始したクイズは、誤採点を避けるため再開始を案内する場合があります。タイトル等だけの変更では成績の版を変えません。

## その他の項目

- 商品：名称・説明・必要ポイント・画像・表示順。実物交換、配送、送料決済は準備中のままです。
- ふるさと納税：返礼品の紹介・金額目安・分類・案内先URL。
- お知らせ：本文と任意の詳細URL。
- 四島紹介：固定4島の説明・写真・補足情報。
- ライセンス：固定5階級の名称・説明・累計ポイント条件。最初の階級は0pt、条件の重複は禁止です。

削除は「公開停止」として扱い、下書きと履歴を残します。取得済みスタンプは利用者の図鑑に残り、新規配布だけ停止します。復元後は別途「公開」が必要です。

## 保護と制限

- 管理APIはFirebase認証、メール確認または検証済みLINE、App Check、サーバー側の管理者許可リストで保護します。
- 権限付与は管理画面からできません。運営が明示的に指定したメール確認済みアプリ登録者に限り、`scripts/grant-content-admin.cjs` を会社アカウントで実行します。認証情報や秘密鍵をブラウザに配置しません。
- 公開カタログのみ一般配信します。下書き、管理権限、QRの原文、操作記録は直接のFirestoreアクセスを拒否します。
- 同時編集による上書きを拒否し、公開変更と監査記録を同じトランザクションで保存します。
- 管理更新は1アカウント1日500操作、各公開カテゴリ150件、1クイズ30問、1問2〜6択。管理用データ量にも上限があります。
- 管理画面で表示する発行済みQRは最大100件、操作記録は直近30件です。さらに件数が必要になった際はページ送りの拡張が必要です。
- 画像は既存素材パスまたはHTTPS URLを指定します。ファイルアップロードは未実装です。
