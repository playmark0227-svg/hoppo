# LINE連携（LIFF）セットアップ手順

このアプリをLINEの中で動かし、リッチメニューから起動できるようにする手順です。
コード側の実装は完了しているので、**あとはLINE側で発行したIDを1か所に貼るだけ**です。

所要時間の目安：30〜40分（LINE公式アカウントの作成を含む）

---

## 全体像

```
利用者 ──タップ──> リッチメニュー ──> LIFF URL ──> GitHub Pages のアプリ
                  (LINE公式アカウント)            (LINEアプリ内で開く。ログイン済み)
```

必要なものは2つです。

| 必要なもの | 何のため | 使うチャネル |
| --- | --- | --- |
| **LIFF ID** | アプリをLINE内で動かし、ログインさせる | LINEログイン |
| **チャネルアクセストークン** | リッチメニューを登録する | Messaging API |

---

## STEP 1. LINE Developers に登録する

1. https://developers.line.biz/ にLINEアカウントでログイン
2. **プロバイダー**を作成（例：`ViFight`）
   - プロバイダー＝アプリの提供者名。利用者にも表示されます。

---

## STEP 2. LINEログインチャネルと LIFF アプリを作る

1. 作成したプロバイダー内で **「新規チャネル作成」→「LINEログイン」** を選ぶ
2. 必要事項を入力（アプリ名・説明・アイコンなど）
   - **アプリタイプは「ウェブアプリ」にチェック**
3. できたチャネルの **「LIFF」タブ → 「追加」**
4. 次のとおり設定します。

   | 項目 | 設定値 |
   | --- | --- |
   | LIFFアプリ名 | 北方領土ステータス |
   | サイズ | **Full**（画面全体。このアプリはフル画面前提のデザインです） |
   | エンドポイントURL | `https://playmark0227-svg.github.io/hoppo/` |
   | Scope | **`profile`** にチェック（名前とアイコンの取得に必要） |
   | ボットリンク機能 | On (Aggressive) ※STEP 4の公式アカウントと連携する場合 |
   | Scan QR | **オン**（LINE内でQR読み取りを使うために必要） |

5. 発行された **LIFF ID**（`2001234567-AbCdEfGh` のような形式）をコピー

> **注意**：エンドポイントURLの末尾のスラッシュを省かないでください。
> また `http://` は使えません（LIFFはHTTPS必須。GitHub Pagesは対応済み）。

---

## STEP 3. LIFF ID をアプリに設定する

`js/config.js` を開き、`liffId` に貼り付けます。**ここだけです。**

```js
window.HOPPO_CONFIG = {
  liffId: '2001234567-AbCdEfGh',   // ← STEP 2 でコピーしたID
  lineAddFriendUrl: ''
};
```

変更したらコミットしてプッシュし、`main` に反映します。
GitHub Pages のビルド完了後（1〜3分）、LIFF URL で開けるようになります。

```
https://liff.line.me/2001234567-AbCdEfGh
```

このURLをLINEのトークに送って自分でタップすると、動作確認ができます。

> **キャッシュに注意**：`sw.js` の `CACHE_VERSION` と `index.html` の `?v=` は
> 必ず一緒に上げてください。上げ忘れると古いJSが配信され続けます。

---

## STEP 4. リッチメニューを設定する

リッチメニューにはLINE公式アカウント（Messaging APIチャネル）が必要です。

### 4-1. Messaging API チャネルを作る

1. 同じプロバイダー内で **「新規チャネル作成」→「Messaging API」**
2. 作成後、**「Messaging API設定」タブ** を開く
3. 下部の **チャネルアクセストークン（長期）** を「発行」してコピー

> **このトークンは絶対にコミットしないでください。** 漏れると公式アカウントを
> 第三者に操作されます。必ず環境変数で渡してください。

### 4-2. メニュー画像を作る

```bash
python3 tools/build-richmenu-image.py
```

`tools/richmenu.png`（2500×1686）が生成されます。
デザインを変えたい場合は同スクリプトの `TILES` を編集してください。
**タップ位置は `tools/setup-richmenu.js` の `TILES` と対応しているので、
順番を変えるときは両方を必ず揃えてください。**

### 4-3. 登録する

```bash
export LINE_CHANNEL_ACCESS_TOKEN='発行したトークン'
export HOPPO_LIFF_ID='2001234567-AbCdEfGh'

node tools/setup-richmenu.js --dry-run   # 送信内容の確認だけ
node tools/setup-richmenu.js             # 実際に登録
```

作り直したいときは `--replace` を付けると既存メニューを削除してから登録します。

```bash
node tools/setup-richmenu.js --replace
```

### 4-4. 確認

公式アカウントを友だち追加してトークを開くと、メニューが表示されます。
すでに開いていた場合は一度閉じて開き直してください。

---

## STEP 5.（任意）友だち追加URLを設定する

LINE Official Account Manager で友だち追加URL（`https://lin.ee/xxxxx`）を取得し、
`js/config.js` の `lineAddFriendUrl` に設定すると、LINE外のブラウザで開いた人に
案内リンクが表示されます。

---

## 動作の仕様

| 開き方 | 挙動 |
| --- | --- |
| **リッチメニュー / LIFF URL**（LINE内） | 起動時に自動でログイン済み。名前とアイコンが入る。**操作は不要** |
| **通常のブラウザ**（github.io を直接） | 自動ではログインしない。設定画面の「LINEでログイン」を押したときだけ連携 |
| **`liffId` が未設定** | LINE連携の項目ごと非表示。外部通信は一切発生せず、従来どおり動作 |

通常ブラウザで自動ログインさせない（＝勝手にLINEへリダイレクトしない）のは意図的です。
何もしていないのに別アプリへ飛ばされるのは利用者にとって不親切なためです。

リッチメニューの各ボタンは `?page=` でアプリ内の画面を直接開きます
（`home` / `quiz` / `qr` / `shop` / `license` / `social`）。

---

## LINE内でのQR読み取りについて

LINEのアプリ内ブラウザはカメラ（`getUserMedia`）が使えない場合があります。
そのため **LINE内では LINE純正のコードリーダー（`liff.scanCodeV2`）** を使い、
それ以外のブラウザでは従来どおり jsQR を使う実装になっています。

LINE内で読み取れない場合は、**LIFF設定の「Scan QR」がオンか**を確認してください。

---

## ⚠️ 現時点でできないこと：データの引き継ぎ

**LINEでログインしても、ポイントや履歴は端末の中だけに保存されます。**

- 機種変更するとデータは引き継がれません
- スマホとPCで別々のデータになります
- LINEアプリ内で開いた場合と、通常ブラウザで開いた場合でも別データです

これは、このアプリにサーバー（バックエンド）が無いためです。
現状のLINEログインは「**名前とアイコンの自動入力＋LINE内で起動できる**」までの機能です。

引き継ぎを実現するにはサーバー側の実装が必要になります。

| 必要なもの | 内容 |
| --- | --- |
| APIサーバー | LIFFのIDトークンを検証し、ユーザーを特定する |
| データベース | ポイント・履歴・実績をユーザーIDに紐づけて保存 |
| ホスティング | GitHub Pages は静的配信のみのため、別途必要（Cloudflare Workers、Vercel など） |

これを入れると、本物のランキングやフレンド機能（現在はローカルのデモ）も
実装できるようになります。必要になったタイミングでご相談ください。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| LINE内で開いても連携されない | `js/config.js` の `liffId` が正しいか。デプロイ済みか |
| 「LINE連携を準備できませんでした」と出る | LIFFのエンドポイントURLが実際のURLと一致しているか（末尾スラッシュ含む） |
| 名前が入らない | LIFF設定の Scope で `profile` にチェックが入っているか |
| アイコンが表示されない | CSPの `img-src` にLINEの配信ドメインが入っているか（`index.html`） |
| QRが読めない | LIFF設定の「Scan QR」がオンか |
| リッチメニューが出ない | 公式アカウントを友だち追加しているか。トークを開き直したか |
| 変更が反映されない | `sw.js` の `CACHE_VERSION` と `index.html` の `?v=` を上げたか |
